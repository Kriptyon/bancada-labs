# Linux esencial

Este codespace es un Ubuntu 24.04 para los **laboratorios 1 y 2** del curso. Abre un terminal (menú Terminal → New Terminal) y sigue el enunciado en Bancada: donde diga «tu servidor» o «la VM», trabaja en este terminal. Tu usuario es `vscode` y puede usar `sudo`.

No hace falta instantánea: si algo sale mal, borra el codespace y crea otro.

A partir del laboratorio 3 (nginx y SSH) necesitas la máquina virtual del curso, porque un codespace es un contenedor sin `systemd` y no sirve para gestionar servicios. La guía para prepararla está en Bancada.
