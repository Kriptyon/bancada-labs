# Desplegar y asegurar una web

Crea aquí el proyecto del laboratorio 1:

```bash
cd /workspaces/bancada-labs/desplegar-asegurar-web
npm create astro@latest clinica-demo
cd clinica-demo && npm run dev -- --host
```
