# HTML, CSS y accesibilidad

- `lab-01/` y `lab-02/`: créalas tú siguiendo el enunciado en Bancada.
- `lab-03/index.html`: la página con errores para auditar y corregir.

Para ver una página: clic derecho sobre el `.html` → **Open with Live Server**. Codespaces abrirá el puerto 5500 en una pestaña nueva.

Las herramientas de desarrollo (F12), Lighthouse y las extensiones de accesibilidad se usan en **tu** navegador, sobre la pestaña de la vista previa.
