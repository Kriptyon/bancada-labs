# Bancada · laboratorios en la nube

Entorno listo para los laboratorios de **Desarrollo web** y de **Programar con agentes de IA** de Bancada. Se abre en tu navegador con GitHub Codespaces: no tienes que instalar nada en tu ordenador.

[![Abrir en GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Kriptyon/bancada-labs)

## Cómo empezar
1. Inicia sesión en GitHub (una cuenta gratuita sirve).
2. Pulsa el botón de arriba y después **Create codespace**.
3. Espera a que se abra el editor y entra en la carpeta de tu curso.

## Cuota y coste
Codespaces se factura a la cuenta de GitHub de quien crea el entorno. A fecha de octubre de 2026, GitHub incluye una cuota gratuita mensual de 120 horas de cómputo y 15 GB-mes de almacenamiento. Las horas se multiplican por los núcleos de la máquina: con 2 núcleos, unas 60 horas reales. Consulta las condiciones vigentes en la [documentación de facturación de GitHub Codespaces](https://docs.github.com/es/billing/managing-billing-for-your-products/managing-billing-for-github-codespaces) y revisa tu límite de gasto en https://github.com/settings/billing. Si superas la cuota y tienes un medio de pago en GitHub, puede cobrarte. Para no gastarla:
- **Detén el codespace** al terminar (menú Codespaces → Stop current codespace).
- **Bórralo** cuando acabes el curso desde github.com/codespaces.

## Seguridad
- No guardes claves reales en el codespace: es un entorno de prácticas.
- Si conectas el codespace a servicios externos (Cloudflare, Claude), hazlo con cuentas personales de prueba y revoca el acceso al terminar el curso.
- Usa cuentas personales y no introduzcas datos personales de terceros (pacientes, clientes) en el codespace.
